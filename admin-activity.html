Activity

Login/logout timestamps and cloud upload events. Use the Uploads tab (or the Uploads table below) and click Download to fetch a draft/submit ZIP or asset from cloud storage. Logout is recorded only on explicit logout — closing a tab or cookie expiry is not logged.

DATABASE_URL is not set — activity history will not persist.
